# Audit: fixed predictor moments in the OpenMx growth-curve models

2 October 2026. Related: `docs/frs_sex_swap_audit.md` (the ADSP-PHC Framingham
sex swap). The corrected-FRS re-run was already under way when this was written.
The fix changes no reported mediation estimate (§4), so it does not need its own
full re-run; §6 says what to do and when.

## 1. Summary

In every OpenMx latent growth curve model, the observed predictors (Framingham or
CVR_mimic, age, education, APOE ε4, and sex in 13b) are manifest variables whose
means are **fixed to 0**, whose variances are **fixed to 1**, and which have **no
covariances** with each other. The data do not match these values: age is in
years (variance about 47 to 51), APOE ε4 is a 0/1/2 count with mean about 0.6,
and Framingham correlates 0.41 to 0.48 with age.

An external review flagged this as a possible bias: "Framingham not age-adjusted;
CVR_mimic's 0 of 6 a-paths possibly distorted". **That concern is wrong for the
point estimates and standard errors in these data.** The predictors are complete
(one missing APOE ε4 value in the women's sample), and their distribution has no
free parameters. So the predictors' contribution to the likelihood is a constant,
and the path estimates equal those of the conditional model (the equivalent of
`fixed.x = TRUE` in lavaan). Every path is therefore a partial coefficient,
adjusted for all the other predictors. A simulation and refits of three real
models in §4 confirm this.

**What the misspecification does affect** (§5):

- absolute −2LL, AIC and BIC values, which the manuscript prints in
  `@tbl-mediation-fit`
- latent means in script 12, where age and education are not centred
- numerical conditioning in script 12, where the fixed moments add about
  3 million to −2LL (§5f)
- anything computed from the model-implied predictor covariance
- the one row with a missing predictor

**Recommended fix** (§6): estimate the predictors' means, variances and
covariances, or fix them to the sample values. This is good practice and costs
little. In script 13 it leaves every path estimate unchanged (§4); in script 12,
check the coupling results after refitting (§5f).

## 4. Why estimates and standard errors are unaffected

Write the model as η = α + Γx + ζ, with y = Λη + ε, and x ~ N(μx, Σx), where μx
and Σx are **fixed**. The joint normal density factorises as p(x) · p(y | x).

- The conditional distribution is p(y | x) = N(Λα + ΛΓx, ΛΨΛ' + Θ). Neither μx
  nor Σx appears in it. Its mean is a multiple regression on **all** predictors
  jointly, so Γ holds partial coefficients.
- p(x) contains no free parameters.

Maximizing the joint likelihood is therefore the same as maximizing p(y | x).
That gives the same point estimates and standard errors as the conditional
(fixed-x) model, whatever fixed values are chosen for μx and Σx. This holds only
if every predictor value is observed.

**Simulation check.** n = 900, five waves. The predictors are on their natural
scales and correlated like the ADNI inputs. The true slope effects are:
`frs` = -0.20, `age` = -0.010, `educ` = 0.01, `apoe` = -0.05. OpenMx results:

| Slope path | Fixed predictor moments (current code) | Free predictor moments | SE fixed | SE free |
|---|---|---|---|---|
| `frs` | -0.1944699 | -0.1944700 | 0.0179112 | 0.0179110 |
| `age` | -0.0094408 | -0.0094407 | 0.0017015 | 0.0017015 |
| `educ` | 0.0173047 | 0.0173046 | 0.0040687 | 0.0040687 |
| `apoe` | -0.0249318 | -0.0249321 | 0.0169592 | 0.0169589 |

- **−2LL:** 71,340.5 with fixed moments against 24,689.9 with free moments. Only
  the constant differs.
- **Reference:** an OLS regression of the true person slopes on all four
  predictors gives `frs` = -0.2065 and `age` = -0.0093.

So the current code's Framingham slope path is age-adjusted. The comparison "FRS
a-path significant, CVR_mimic not" is not an artefact of this issue. It does
depend on the sex swap, which is a separate matter.

Simulation code (rerun it from the repo root with the project's R):

```r
suppressMessages({library(OpenMx); library(MASS)})
set.seed(1)
n <- 900; tp <- 0:4
age <- rnorm(n, 0, sqrt(48)); frs <- 0.45 * age / sqrt(48) * 0.7 + rnorm(n, 0, 0.6)
educ <- rnorm(n, 0, sqrt(7.2)); apoe <- rbinom(n, 2, 0.3)
i <- 0.02 * age + rnorm(n, 0, 1)
s <- -0.20 * frs - 0.010 * age + 0.01 * educ - 0.05 * apoe + rnorm(n, 0, 0.3)
Y <- sapply(tp, function(t) i + s * t + rnorm(n, 0, 0.5)); colnames(Y) <- paste0("y", tp)
d <- data.frame(Y, frs = frs, age = age, educ = educ, apoe = apoe)
preds <- c("frs", "age", "educ", "apoe"); yv <- colnames(Y)
build <- function(fixed_exo) {
  m <- mxModel("g", type = "RAM", manifestVars = c(yv, preds), latentVars = c("i", "s"),
    mxPath("i", yv, free = FALSE, values = 1), mxPath("s", yv, free = FALSE, values = tp),
    mxPath(yv, arrows = 2, free = TRUE, values = 0.3, labels = "e"),
    mxPath(c("i", "s"), arrows = 2, connect = "unique.pairs", free = TRUE, values = c(1, 0, 0.1)),
    mxPath("one", c("i", "s"), free = TRUE, values = 0), mxPath("one", yv, free = FALSE, values = 0),
    mxPath(preds, c("i", "s"), connect = "all.pairs", free = TRUE, values = 0,
           labels = c(paste0(preds, "_i"), paste0(preds, "_s"))[order(rep(1:4, 2))]),
    mxData(d, type = "raw"))
  if (fixed_exo) {
    m <- mxModel(m, mxPath(preds, arrows = 2, free = FALSE, values = 1),
                    mxPath("one", preds, free = FALSE, values = 0))
  } else {
    m <- mxModel(m, mxPath(preds, arrows = 2, connect = "unique.pairs", free = TRUE,
                           values = diag(4)[lower.tri(diag(4), diag = TRUE)] + 0.01),
                    mxPath("one", preds, free = TRUE, values = colMeans(d[preds])))
  }
  mxRun(m, silent = TRUE)
}
a <- build(TRUE); b <- build(FALSE)
```

**Real-data check.** `docs/lgcm_exogenous_check.R` refits three script-13
mediation models on the corrected-FRS inputs (point estimates only, no
bootstrap), once with the current fixed moments and once with estimated moments
(Option A in §6). The fixed-moment fits reproduce the pipeline's checkpoints
exactly.

| Model | Largest change in a, b, c′ | Largest change in SE | −2LL, fixed → estimated |
|---|---|---|---|
| Male MEM, FRS | 4 × 10⁻⁷ | 2 × 10⁻⁶ | 34,831 → 10,018 |
| Male MEM, CVR_mimic | 9 × 10⁻⁷ | 7 × 10⁻⁶ | 35,177 → 10,861 |
| Female MEM, CVR_mimic (1 missing APOE ε4) | 1 × 10⁻⁵ | 4 × 10⁻⁶ | 30,401 → 8,865 |

The bootstrap CIs follow, since every resample is a refit of the same kind. In
script 13 the fixed moments add about 22,000 to 25,000 to −2LL (centred age,
variance about 48); in script 12 they add about 3 million (§5f), so this check
does not carry over there.

## 5. What the current specification does affect (check each)

a. **Absolute −2LL, AIC and BIC.** These are offset by the predictors' (wrong)
   log-likelihood.
   - **Valid:** comparisons between models with the **same predictor set and the
     same rows**. Examples: linear against fixed-quadratic AIC in script 12
     (about 1366-1385); the HVR residual LRT (Δχ² = 35.0) in
     `docs/openmx_audit/`.
   - **Invalid:** any comparison across different predictor sets, such as FRS
     models against CVR models, or with against without a predictor.
   - **In the manuscript:** `@tbl-mediation-fit` prints absolute −2LL, AIC and
     BIC for every mediation model, with FRS and CVR_mimic columns side by side,
     and the Methods say fit "was assessed via −2LL, AIC, BIC, and nested LRTs".
     Remove the absolute values (or the table) and keep the nested LRTs.
   - The manuscript already avoids CFI, TLI and RMSEA for these models (about
     line 1315); keep it that way, because they would also be wrong.
b. **Latent means in script 12.** `AGE_bl` and `EDUC` are raw, with means fixed
   at 0, so the latent intercept and slope means α are values at **age 0 and 0
   years of education**: an extrapolation, not a population average.
   - `R/scripts/14_lgcm_simulation.R` (about 95-125) hard-codes
     `slope_mean = -0.19` "averaged across 6 sex × domain models". Check where
     that number came from. If it came from script 12's α, it is the
     extrapolated value.
   - Hard-coding it also conflicts with this repo's rule that every number must
     load from an RDS file.
   - The fixed-quadratic model (`create_fixedquad_parallel.fn`, built on
     `create_linear_parallel.fn`) has age, education and APOE ε4 paths to the
     slopes as well as the intercepts, so the slope means are age-0 values too.
     For Male MEM the HVR slope mean is +0.157 at age 0, against −0.208 for a
     participant at the sample means (age 74.8, education 16.5, APOE ε4 0.60).
   - The manuscript's `lgcm-growth-inline` chunk is meant to report these slope
     means ("mean HVR slopes were negative across all domains"). It reads a
     `summary` element that the results have never contained, so it currently
     prints nothing. Centre the covariates before repairing it, or it will
     report the age-0 values.
   - In script 13, `AGE_c` and `EDUC_c` are centred, but `APOE4_num` is not, so
     the latent means there are values for APOE ε4 non-carriers. That is fine,
     but say so wherever a latent mean is reported.
c. **The one missing APOE ε4 value (women).** Under FIML that row is integrated
   over the misspecified N(0, 1) distribution. The effect is negligible (about
   1 × 10⁻⁵ on the Female MEM paths, §4), and it disappears with the fix.
d. **Anything computed from the model-implied predictor covariance.** Examples
   are `mxStandardizeRAMpaths`, standardized a- and b-paths, and R² of the latent
   slopes. These would use variance 1 for age instead of about 48. None was
   found in scripts 12, 13, 13b or 15, but check before adding any.
e. **Scale, separate from this issue.** `FRS_c` and `CVR_sex_centered` are
   globally z-scored and then centred within sex, so one unit is one *global*
   SD. With the corrected score, men's `FRS_c` variance is 0.22 against 1.20 in
   women, so a men's a-path "per unit" is per global SD, and comparing a-path
   magnitudes across sexes needs care.
f. **Numerical conditioning in script 12.** Raw `AGE_bl` (mean about 73) and
   `EDUC` (about 16) evaluated against N(0, 1) add about 3.0 million (men) and
   2.2 million (women) to −2LL. In the 2 October run the fixed-quadratic fits
   reached −2LL of 3,010,528 to 3,012,005 (men) and 2,241,553 to 2,242,350
   (women), so almost all of the value being optimized is this constant.
   Symptoms in that run (`logs/pipeline_20261002_105022.log`; the OpenMx
   status-code warnings went to the console and are not in that log):
   - OpenMx returned status code 5 ("The Hessian at the solution does not
     appear to be convex", Mx status RED) eight times for the
     `FixedQuadParallel` models, which are the ones the manuscript reports;
     the reported coupling p-values are Wald tests from that Hessian;
   - 10 of 36 parameters in Male MEM and 2 in Male EXF have no SE;
   - the Male MEM fit ended "Retry limit reached" (3 of 6 attempts errored);
   - the nested coupling LRT returned a result for only 2 of 6 models (3 of 6 in
     the pre-correction run);
   - all six fully random quadratic attempts ended "Converged but UNRELIABLE"
     (maximum SE about 4,000 to 33,000). The manuscript (about lines 1290 and
     2795) gives this failure as the reason for the fixed-quadratic model.

   Whether the coupling results, and the random-quadratic failure, survive a
   refit with centred covariates and correct moments is untested. Script 12
   refits on its own in about 25 minutes.

## 6. Recommended code change

Use one consistent specification in scripts 12, 13, 13b and
`docs/openmx_audit/run_lrt.R`.

**Option A.** Estimate the predictors' moments. This is a saturated exogenous
block; under FIML it also treats missing predictor values correctly.

```r
pred_cov <- mxPath(
  from = preds, arrows = 2, connect = "unique.pairs",
  free = TRUE,
  values = cov(data[, preds], use = "pairwise")[lower.tri(diag(length(preds)), diag = TRUE)],
  labels = NA
)
pred_mn <- mxPath(
  from = "one", to = preds, free = TRUE,
  values = colMeans(data[, preds], na.rm = TRUE)
)
```

Starting values must follow the order that `unique.pairs` expects. Check this in
the OpenMx documentation, or use `mxAutoStart()`.

**Option B (recommended).** Fix the moments to their sample values. This is
lavaan's `fixed.x = TRUE`: it adds no parameters and is equivalent to Option A
for complete data. With the one missing APOE ε4 value the two differ by about
1 × 10⁻⁵ (§4).

**Also:** centre `AGE_bl` and `EDUC` in script 12 (as in script 13), so that latent
means refer to the sample's average person. In script 12 this is also what
removes the large −2LL constant (§5f).

**Checkpoints.** Script 13 reuses bootstrap checkpoints whatever
`force_regenerate` says, and its validity check (`bootstrap_n`, `shared_seed`,
`fixed_quad`, `boot_all_ci`) knows nothing about the predictor specification.
Add a flag for it, or old and new fits will be mixed and their stored fit
indices will disagree.

**When.** After the corrected-FRS re-run finishes, not during it. Refit script 12
on its own first and compare the coupling results (§5f). The script 13 and 13b
changes can wait for the next full re-run, since no reported estimate depends
on them.

**Acceptance tests** (add them as unit tests):

1. For one model per script, refit with the old and new specifications. Every
   path estimate and SE should agree to at least 4 decimals, as in §4. Only
   −2LL, AIC and BIC (and latent means in script 12) should change. Done for
   script 13 (`docs/lgcm_exogenous_check.R`); script 12 is the one to watch.
2. The model-implied predictor covariance should equal the sample covariance.
3. After the change, any cross-model AIC or BIC comparison used in the
   manuscript is valid. Recompute and report them.

## 7. Correction of earlier claims

A review of the FRQS package (grants repo,
`applications/frqs-2027/reviews/2026-10-02_audit_full_package.md`, section C)
said this "would affect the LGCM a-paths, including the
measure's 0 of 6", and that Framingham was "not age-adjusted". **Both claims are
withdrawn.** With complete predictors and fixed predictor moments, the estimates
are the conditional, fully adjusted ones (§4). Before the fix, the issue matters
only for §5.
